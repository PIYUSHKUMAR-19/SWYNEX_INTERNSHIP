# ♟️ Chess Game Analysis Dashboard | Power BI

## 📌 Project Overview
This project analyzes **19,524 chess games** to explore game outcomes, player rating advantages, game length, and opening strategies. Using Excel for data preparation and Power BI for visualization, the project transforms raw chess data into meaningful insights.

## 🎯 Project Objectives
- Analyze White wins, Black wins, draws, and unknown outcomes.
- Investigate the relationship between player ratings and game results.
- Understand game-length patterns and draw rates.
- Identify popular chess openings and compare their recorded outcomes.
- Build an interactive, multi-page Power BI dashboard.

## 🛠️ Tools & Technologies
- **Microsoft Excel:** Data cleaning, formatting, and exploratory data analysis (EDA).
- **Power BI:** Interactive dashboards, charts, slicers, and DAX measures.
- **DAX:** KPI calculations, win rates, draw rates, and opening analysis.

## 📊 Dashboard Pages

### 1. Executive Overview
Provides a high-level summary of the chess dataset, including total games, overall results, and key performance indicators.

### 2. Results & Rating Advantage
Examines White and Black victories, decisive game outcomes, and how differences in player ratings relate to results.

### 3. Game Length Analysis
Explores move-count distributions, game-length groups, median move count, and draw rates across different game lengths.

### 4. Opening Strategy
Analyzes opening popularity, opening coverage, outcome distribution, White vs. Black decisive win rates, and median moves by opening.

## 🔍 Key Findings
- **19,524** chess games were analyzed.
- White won **9,617 games**, while Black won **8,787 games**.
- The dataset contained **901 draws** and **219 unknown or other outcomes**.
- The median recorded move count was **55**.
- **5,953 games** contained between 61 and 100 moves.
- Opening analysis compares popularity and recorded outcomes rather than assuming that the most popular opening is the most successful.
